# Singlish to Sinhala Translator – Playwright Automation Tests

## 📌 Project Overview
This project contains automated test cases written using **Playwright** to test a **Singlish to Sinhala Translator web application**.  
The purpose of this project is to validate the **functional behavior** and **UI behavior** of the system as part of **Assignment 1 – IT3040 (ITPM)**.

The tests verify:
- Real-time Singlish to Sinhala conversion
- Handling of valid and invalid inputs
- UI element visibility and behavior
- Cross-browser compatibility

---

## 🧪 Test Types Covered

### ✅ Functional Test Cases
- Positive Functional Tests (`Pos_Fun`)
- Negative Functional Tests (`Neg_Fun`)

### 🎨 UI Test Cases
- Positive UI Tests (`Pos_UI`)
- Negative UI Tests (`Neg_UI`)

### 🌐 Browsers Tested
- Chromium
- Firefox
- WebKit
